**一句话说清楚这家公司**：Alphabet 就是谷歌，它靠"搜索广告"这台印钞机起家（你每次用 Google 搜索东西，旁边的广告点一下它就赚钱），现在又把利润投入到云计算（出租服务器算力给企业）和自研 AI 芯片、AI 大模型（Gemini）上，试图从"广告公司"转型成"全栈 AI 公司"。

**核心投资逻辑（一句话）**：市场担心 AI 聊天机器人（如 ChatGPT）会革掉谷歌搜索广告的命，但过去四个季度的真实财报数据证明，谷歌不仅没被革命，反而靠 Gemini + AI Overviews 把用户和广告主一起留住，同时云计算业务利润率三年内从"烧钱"变成"印钞"，这是市场尚未完全定价的预期差。

**三大支撑论据**：
① 搜索业务在 AI Overviews 月活 20 亿+ 的冲击下仍录得两位数增长——2026年Q2 Search & other 收入 $63.3B，同比 **+17%**（来源：Alphabet Q2 2026 财报，2026-07-22）；
② Google Cloud 收入 $24.8B，同比 **+82%**，经营利润率从去年同期 20.7% 提升到 **35.6%**，backlog 达 **$514B**（来源：同上，管理层电话会）；
③ 估值上，GOOGL 的 Forward P/E（约26x）仍低于微软（约27x）、明显低于近一年涨幅更大的同类科技巨头，PEG 约 1.2，在"七巨头"中属于估值最不夸张的一档（来源：多家聚合数据，2026年8月）。

**最大风险（Thesis Breaker）**：2026年Q2 自由现金流历史上首次转负（**-$5.9B**），全年 capex 指引被上调至 **$195–205B**（原为$180–190B），管理层同时预告 2027 年 capex "将显著进一步增加"；如果这轮资本开支超级周期最终换不回相应的云收入/利润，Alphabet 将和其他超大规模云厂商一起面临"AI 泡沫"式估值重定价（来源：Alphabet Q2 2026 财报电话会，CFO Anat Ashkenazi，2026-07-22）。此外，广告技术反垄断案（Brinkema 法官）救济裁决仍未落地，一旦强制剥离 AdX/DFP，将冲击约占广告收入链条重要一环的业务模式。

## 第一章：公司背景——这家公司是谁？

**【小白导读】** 这一章回答的问题很简单：谷歌是从哪来的、现在归谁管、公众买的股票有没有真正的话语权。答案是——你能买到的谷歌股票（代码 GOOGL/GOOG）虽然叫"投票权"，但公司创始人拉里·佩奇和谢尔盖·布林通过一种特殊股票（B类股，不上市交易，每股10票）依然掌握着超过一半的投票权，也就是说，即便你买再多普通股票，也无法通过投票改变公司的战略方向。这是理解 Alphabet 治理结构最重要的一件事。

**1.2 发展历史（关键节点）**

- 1998年：Google 成立于车库；核心产品搜索引擎。
- 2000年：AdWords（现Google Ads）上线，广告业务引擎启动。
- 2004年：Google 上市（IPO），首次采用双重股权结构（A/B股）。
- 2005-2015年：收购 Android（2005）、YouTube（2006）、DoubleClick（2007）等，逐步搭建"搜索+移动+视频+广告技术"全生态。
- 2015年：重组为 Alphabet Inc. 控股公司架构，Google 成为其子公司，同时孵化"Other Bets"（Waymo自动驾驶、Verily生命科学等前沿业务）。
- 2016年：CEO Sundar Pichai 提出"AI-first"战略。
- 2023年：ChatGPT 引爆的生成式AI浪潮一度令市场质疑谷歌"AI落后"，股价承压。
- 2024-2026年：Gemini系列模型迭代加速（Gemini 3于2025年11月发布），云计算利润率大幅改善，谷歌完成从"AI落后者"到"全栈AI领军者"叙事的逆转；2026年Q2首次实现单季度营收破 **$1198亿**（来源：Alphabet Q2 2026财报，2026-07-22），但同时也在这一时期首次出现单季度自由现金流为负。
- 2026年：欧盟对谷歌开出首张《数字市场法》(DMA)罚单（7月23日，€890M）；同时安卓反垄断案的欧盟终审罚款（$5.2B）在7月支付完毕，该案彻底了结（来源：Alphabet 2026年Q2 10-Q，Note 10）。

**1.3 公司定位**

市场目前把 Alphabet 当作"成长股 + 现金牛"的混合体来定价：核心广告业务贡献稳定现金流（毛利率约80%+的Search业务），而云计算和AI基础设施（TPU芯片、Gemini模型）被当作第二增长曲线，享受成长股估值溢价。管理层的对外叙事是"全栈AI公司"（模型+芯片+数据中心+分发渠道，四层都自有），这与其当前收入结构（约80%来自广告）存在一定的"故事跑在数字前面"的张力——需要持续观察云计算收入占比是否能真正提升到与叙事匹配的量级。

**1.4 股权结构（本报告最重要的公司治理事实）**

| 股东类型 | 持股/投票权情况 | 来源 |
|---|---|---|
| Larry Page（联合创始人，董事） | 持有B类股，单独约27.4%投票权 | SEC文件相关披露，2026-04-06 |
| Sergey Brin（联合创始人，董事） | 持有B类股，单独约25.3%投票权 | 同上 |
| 佩奇+布林合计投票权 | 约 **52.7%**（对Class B普通股持股比例约89.4%） | SEC文件，2026-04-06 |
| 机构投资者持股（占流通股比例，非投票权） | 约40.03%机构持股比例，5,791家机构持有者 | Fintel.io聚合数据，2026年 |
| 最大机构股东 | Vanguard Group，持股约5.17亿股（约$91.03B），2026年Q2再增持1.3% | 聚合13F数据，2026年 |
| 知名新进/加仓机构 | Berkshire Hathaway（巴菲特旗下）2026年Q2大幅加仓83%，Class A持股从5,425万股增至7,879万股（+45%），叠加C类股，合计约1.06亿股（约$36.6B），成为伯克希尔第三大重仓股 | CNBC/Forbes/Yahoo Finance，2026-08-15（基于Q2 2026 13F） |

**关键含义**：这是一家"创始人控制型"公司——即便外部股东（包括伯克希尔这样的巨头）合计持有更多股份，也无法在董事会层面否决佩奇和布林的意志。这既是治理折价的来源（外部股东无法"纠正"管理层的错误决策，例如过度激进的capex），也是长期战略稳定性的来源（管理层不会因短期股东压力放弃AI基础设施的长期投入）。

**【本节结论】** Alphabet 本质上是一家由创始人通过超级投票权牢牢掌控的"准家族企业"式科技巨头——这不是负面标签，而是理解其一切战略决策（尤其是近两年不计代价押注AI capex）的钥匙：管理层完全可以无视短期股价波动和机构股东的异议，把巨额自由现金流甚至新发的债务和股权持续砸向AI基础设施。对投资者而言，这意味着买入GOOGL在某种程度上等于对佩奇、布林、皮查伊三人的长期AI判断投下信任票，而不是传统意义上"用脚投票"就能影响公司走向的普通股权投资。

## 第二章：行业分析——它所在的赛道值不值得看？

**【小白导读】** Alphabet 同时活在三个不同的"赛道"里：卖广告（数字广告市场）、出租云端算力（云计算市场）、以及一场决定未来十年科技格局的AI大模型竞赛。这一章要回答：这三个赛道各自有多大、还能不能继续增长、谷歌在里面排第几。

**【专业深挖】**

**2.1-2.2 行业空间与驱动因素**

**2.3 行业周期**：AI相关的云计算与芯片支出目前处于历史性的资本开支狂热期——美股五大超大规模云厂商2026年合计资本开支指引合计约$635-690B，是2024年水平的两倍以上，且capex增速已经跑赢云收入增速，这是当前全行业最大的尾部风险（来源：Futurum Group/Introl/American Century行业研究，2026年）。数字广告业务本身周期性较弱，跟随GDP和电商增长稳步扩张；云计算和AI芯片则处于"军备竞赛"式的上行周期顶部区域，一旦企业AI投资回报（ROI）不及预期，全行业存在减记（write-down）风险。

**2.4 竞争格局关键变化（2025-2026）**

- 搜索引擎市场：谷歌全球市场份额从2023年的90.9%小幅降至2026年7月的89.46%-89.82%（微幅侵蚀，非坍塌）——来源：StatCounter，2026-07。
- AI聊天应用市场份额变化剧烈：ChatGPT网页访问份额从2026年1月的约60.7%降至2026年8月的约53.9%，Google Gemini份额从15.0%升至27.9%（来源：higoodie.com AI搜索流量报告，2026年8月，另一数据点来自sedestral.com，2026年1月）——趋势清晰：谷歌在AI聊天入口的份额正在快速追赶，但ChatGPT仍保持约2倍领先优势。
- 云计算市场份额（2026年Q2，Synergy Research）：AWS 28%（同比降2pp）、Azure 20%、**Google Cloud 15%**（历史新高，从Q1的约14%突破15%）——三大厂商合计约63%，剩余市场持续向头部集中。

**2.5 波特五力评分（1-10分）**

| 供应商议价权 | 6/10 | 对台积电（芯片代工）、Nvidia（GPU）存在依赖，但通过TPU自研+英特尔代工多元化（2026年6月与Intel签约300万+片TPU代工）显著降低了议价权风险 |

**2.6 区域市场**：谷歌广告与云业务全球化程度极高，北美/欧洲为收入主力区域；中国大陆业务自2010年起基本清零（唯一未大规模布局的主要经济体），这使其在中美科技脱钩背景下对华风险敞口反而是美股七巨头中最小的一家（详见第六章）。欧盟是监管风险最集中的区域（DMA、广告技术反垄断罚款持续发生）。

**【本节结论】** Alphabet 横跨的三个赛道呈现出截然不同的成熟度：数字广告是成熟期但仍在稳定增长（受AI原生广告形态如AI Overviews变现驱动）；云计算处于渗透率仍不到50%的加速扩张期，是三大厂商中增速最快的一家（+82% vs Azure +43%、AWS +36.7%）；AI大模型赛道则完全是格局未定的战场，谷歌凭借Gemini和TPU全栈优势跻身第一梯队，但ChatGPT在用户心智和使用量上仍保持结构性领先。综合看，这是一个"有钱赚、还在增长、但竞争烈度和资本开支强度都在历史高位"的行业组合，值得长期关注但不适合"躺赢式"持有。

## 第三章：商业模式——它到底怎么赚钱？

**【小白导读】** 简单说，谷歌赚钱的方式是：你搜索"哪里买运动鞋"，页面上出现的广告，商家为这次展示/点击向谷歌付费——这就是谷歌80%以上收入的来源。近几年谷歌又多了一条赚钱路子：把自己的服务器算力和AI模型能力，按小时/按用量出租给企业客户（比如Anthropic公司训练AI模型要用谷歌的芯片和服务器），这块叫"Google Cloud"，增长速度比广告业务快得多。

**【专业深挖】**

**3.1-3.2 收入结构（2026年Q2实际数据，总营收$119.8B，同比+24%）**

| 业务线 | Q2 2026收入 | 同比增速 | 占总营收比例 | 商业模式说明 |
|---|---|---|---|---|
| Google Search & other（搜索广告） | $63.3B | **+17%** | 52.8% | 按点击/展示付费的竞价广告，边际成本极低 |
| YouTube ads（YouTube广告） | $11.1B | +13% | 9.3% | 视频贴片/信息流广告 |

**3.3-3.6 商业模式质量与利润结构**

- **广告业务**：极高质量的现金牛——意图流量变现，边际成本接近于零，历史毛利率约80%以上。Google Services经营利润率高达 **41.8%**（Q2 2026），是公司主要利润来源。
- **云计算业务**：规模效应拐点已经出现——Cloud经营利润率从去年同期的20.7%提升到 **35.6%**，经营利润超过三倍增长至$8.8B（来源：Alphabet Q2 2026财报电话会，Anat Ashkenazi）。但管理层同时警示：由于当前算力供给受限，公司计划2026年Q3扩大使用第三方（租赁）算力作为过渡策略，"这将在短期内造成温和的利润率压力"（原话，同上）。
- **Other Bets（含Waymo）**：仍处于战略性亏损阶段，Q2 2026经营亏损约$1.8B。
- **公司层面共同AI研发支出**："Alphabet级别活动"经营亏损约$5.8B，主要为跨部门共享的AI基础研发投入。

**3.7 商业模式质量总评**：广告业务客户高度分散（无单一大客户依赖），转换成本较低但用户习惯粘性极强（Google已是数十亿用户的默认动作）；云计算业务转换成本高（企业一旦迁移工作负载到某云平台，重新迁移成本巨大），且backlog（未来待确认收入）达到 **$5140亿**（Q2 2026，管理层表述"季度环比增加超过$500亿"），其中预计未来24个月内确认收入的比例"略超过50%"——这为未来两年云收入提供了极高的可见性。

**【本节结论】** Alphabet 目前仍是一家"靠广告赚钱、靠云计算讲故事"的公司——广告贡献了近70%的收入和绝大部分利润，云计算虽然收入占比只有约21%，但增速（+82%）和利润率改善速度（20.7%→35.6%）都远超广告业务，是公司估值叙事从"搜索引擎公司"切换到"全栈AI公司"的核心支点。真正需要投资者持续跟踪的信号是：云计算收入占比能否在未来2-3年内提升到30%以上，以及backlog能否如期转化为实际确认收入——这决定了当前巨额资本开支的投资回报能否兑现。

## 第五章：护城河分析——它凭什么长期赢？

**【小白导读】** "护城河"是投资圈的黑话，意思是——这家公司的竞争优势能不能防止对手抢走它的生意，就像古代城堡外面挖的壕沟。这一章逐项打分，看谷歌的护城河到底有多深、有没有正在被填平的地方。

**【专业深挖】**

| 护城河类型 | 评分 | 核心证据 |
|---|---|---|
| 品牌（用户是否愿为品牌付溢价） | 8/10 | Google已成为"搜索"的代名词（动词化品牌），全球市场份额约89.5%（StatCounter，2026-07）；但AI时代的品牌心智争夺战仍在进行中 |
| 成本优势（规模采购/自建供应链/自动化） | 8/10 | TPU自研使AI推理成本显著低于依赖Nvidia GPU的对手（业内估算低30-50%，[精确数字待查]）；2026年6月与Intel签约代工300万+片TPU，进一步分散台积电依赖 |
| 网络效应（用户越多产品越好/数据越多算法越强） | 8/10 | 数十亿次日搜索查询构成的意图数据飞轮，广告主定向能力难以被复制；Search、YouTube、Android、Gmail、Chrome、Maps六大10亿+用户产品互相导流 |
| 技术壁垒（领先多久/对手追赶难度） | 8/10 | 全栈AI能力（模型+芯片+数据中心+分发）目前全球唯一；Gemini 3.1系列在多项基准测试中与GPT-5.5、Claude Opus 4.8同处第一梯队 |
| 渠道与生态（是否掌握用户入口/闭环生态） | 9/10 | Android覆盖全球约30亿设备，Chrome、YouTube等构成的分发闭环是任何AI原生创业公司短期内无法复制的 |

**核心裂缝**：护城河六项中评分最容易被侵蚀的是"品牌"与"网络效应"——如果"问AI"这个行为习惯性地绕过Google Search直接发生在ChatGPT或其他AI助手中，谷歌数十年积累的搜索意图数据飞轮将逐步失去增量数据来源。这是护城河体系中唯一真正意义上的裂缝，其余五项（成本、技术、渠道、转换成本）目前均处于同业最强或并列最强梯队。

**【本节结论】** Alphabet 的护城河综合评分 8.3/10，属于同业顶尖水平，且与竞争对手相比呈现出罕见的"全维度均衡强势"特征——多数科技巨头往往只在一两个维度建立绝对优势（如Meta的网络效应、AWS的转换成本），而Alphabet在六个维度上均处于第一梯队。真正决定这条护城河未来五年是加深还是变浅的唯一变量，是AI聊天式交互能否真正替代传统搜索行为——这也是本报告后续风险章节反复强调的核心跟踪指标。

## 第六章：地缘政治与供应链韧性

**【小白导读】** 这一章看谷歌会不会因为国际政治事件（比如中美关系、关税、芯片禁令）突然被"一票否决"，导致公司估值逻辑整个改变。

**【专业深挖】**

- **6.1 地理集中度**：总部与研发高度集中在美国加州；数据中心全球分布但核心研发决策权集中于美国本土。
- **6.2 出口管制与关税**：2026年6月，美国商务部明确AI芯片出口禁令即使中国企业身处中国境外也适用（来源：Al Jazeera，2026-06-01）；2026年8月19日，美国进一步收紧针对英伟达相关芯片出口中国的漏洞（来源：CNBC，2026-08-19）——这类政策整体针对行业而非专门针对谷歌，但会间接影响谷歌TPU供应链（依赖台积电及其他先进制程代工）及云服务在受限地区的部署。
- **6.3 供应链多元化**：2026年6月，Alphabet与英特尔签署代工协议，采购300万片以上TPU芯片（2028年前交付），这是英特尔代工业务首次获得主流云厂商的量产订单，被视为对台积电单一依赖的实质性对冲（来源：Semicon Electronics，2026年6月）。
- **6.4 关键环节依赖**：TPU芯片制造仍高度依赖台积电先进制程，台海地缘政治风险是谷歌与整个AI硬件行业共同承担的尾部风险，[具体依赖比例待查]。
- **6.5 货币与主权风险**：Alphabet 2026年新发行债券覆盖多币种、多地区（CFO原话："一年前我们大约有160亿美元债务，现在已经扩展到约1000亿美元，覆盖多个货币和地区"，2026-07-22财报电话会），一定程度上分散了单一货币融资风险，但也意味着汇率波动对利息成本的敞口在扩大。
- **6.6 中国大陆敞口**：谷歌自2010年起基本退出中国大陆主营业务（搜索被屏蔽），是美股七巨头中对华业务收入敞口最小的公司之一；2026年3月Gemini在香港首次开放使用，但中国大陆仍完全屏蔽（来源：聚合Gemini可用性追踪，2026年）。这意味着中美科技全面脱钩情景下，谷歌受到的直接业务冲击反而小于苹果、英伟达等公司，但仍会通过芯片供应链（台积电）间接承压。

**极端情景假设**：若台海爆发军事冲突导致台积电产能中断，Alphabet的TPU供应链将遭受重大打击（英特尔代工产能爬坡需要时间，短期内无法完全替代）；若中美AI出口管制进一步升级至云服务层面，Google Cloud在部分地区的企业客户拓展可能受限，但由于中国大陆本就非其核心市场，边际影响相对可控。

**【本节结论】** 相比苹果（供应链高度绑定中国制造）和英伟达（收入高度依赖对华芯片出口），Alphabet 的地缘政治敞口在七巨头中属于结构性最低的一档——中国大陆业务基本为零、且已开始通过英特尔代工分散台积电依赖。但这不意味着"零风险"：台海地缘政治仍是整个AI硬件供应链的共同尾部风险，且不排除未来出口管制政策扩展到云服务/AI模型层面波及谷歌的可能性。

## 第八章：资本配置与股东回报质量

**【小白导读】** 这一章专门审视：管理层赚到的每一块钱，到底是真的在给股东创造价值，还是在"打水漂"。

**【专业深挖】**

**8.1 ROIC vs WACC**：Alphabet长期ROIC维持在约25-26%区间（[不同数据源存在10-45%不等的巨大差异，主要因计算口径不同，本报告采用较为主流的TTM息前税后口径约26.4%]，来源：mlq.ai聚合数据，2026年），估算WACC区间约9.0-12.68%（详见第十三章WACC拆解）。即便采用WACC区间上限，ROIC-WACC利差依然维持在正14个百分点左右——说明公司整体投入资本的边际回报依然显著高于资本成本，增长是在创造价值而非单纯做大规模。

**8.2 再投资率与边际回报**：2025年capex $91.4B，2026年指引跃升至$195-205B，接近翻倍以上——这是公司历史上最激进的再投资率跃升，边际回报能否维持历史水平（云利润率能否继续改善）是决定未来价值创造能否延续的核心变量，[2026-2027年的边际投入产出比尚无法量化，需等待后续季度数据]。

**8.3 股票回购的时机与价格**：历史上（2022-2025年）回购主要在股价相对低估区间执行，事后回看时机较优；但2026年上半年降至**零回购**，这不是"高买低卖"式的价值摧毁，而是主动将资本优先配置到capex——判断这一决策是否正确，本质上等同于判断本轮AI基础设施投资的长期回报率。

**8.4 股权激励稀释效应**：[Alphabet最新SBC占收入/利润比例的精确数据，以及过去3-5年股本净增/净减的具体数字，本次检索未获得足够精确、可交叉验证的最新数据，标注为数据待查]；已知定性信息：截至Q2 2026的ATM股票发行计划（最高400亿美元Class A/C股票）主要用途被管理层明确表述为"覆盖股权激励相关的税务义务"，而非常规融资，反映SBC规模较大是公司持续面临的股本稀释来源。

**8.5 历史并购的事后评估**：YouTube（2006年，$16.5亿收购）、DeepMind（2014年）、Android（2005年，约5000万美元收购）均被广泛认为是科技史级别的成功收购案例；Motorola Mobility（2012年收购、2014年出售）被认为是历史上少数失败案例。近年无重大并购整合失败先例，历史并购整体评价优秀。

**8.6 股息政策**：2024年4月首次宣派股息（季度$0.20/股），2025年6月上调至$0.21/股，2026年6月再次上调至**$0.22/股**（来源：TIKR/SEC 10-Q整理，2026年）；当前年化股息$0.88/股，股息率约0.24-0.26%（基于约$340-358股价区间）——股息率极低，派息更多是象征意义上向机构股东传递"现金流稳健"信号，而非实质性股东回报工具，真正的股东回报主力历来是回购（但2026年上半年已暂停）。

**【本节结论】** Alphabet的资本配置历史记录整体优秀（ROIC远超WACC、历史并购成功率高、回购时机总体理性），但2026年正在经历一次罕见的"资本配置范式切换"——从"稳健回购+适度capex"转向"暂停回购+史无前例的举债扩张capex"。这本身不是负面信号（因为ROIC-WACC利差仍为正），但显著提高了本轮投资周期的执行风险敞口：如果2027-2028年云收入/AI变现不及预期，当前"资本配置质量优秀"的历史评价可能需要重新评估。

- 净利率：32.8%（含一次性股权重估收益，剔除后估计核心净利率约25-28%，[精确剔除口径待查]）

## 附录A：新手术语速查表

| 术语 | 大白话解释 |
|---|---|
| 10-K / 10-Q | 上市公司必须向美国证监会(SEC)提交的年度/季度详细财务报告，是最权威的官方数据来源 |
| GAAP / 非GAAP | GAAP是美国通用会计准则下的"官方"利润数字；非GAAP是公司自己调整(比如剔除一次性收益)后的"口径"，Alphabet不披露非GAAP EPS |
| EPS（每股收益） | 公司净利润除以总股数，衡量每一股能分到多少利润 |
| P/E（市盈率） | 股价除以每股收益，数字越高代表市场愿意为1块钱利润付出更多的价钱（也可能是高估或高增长预期） |
| Forward P/E（预期市盈率） | 用"未来预计利润"而非"过去已实现利润"算出来的市盈率，更能反映市场对未来的预期 |
| PEG | 市盈率除以盈利增速，用来判断"贵不贵"时把增速也考虑进去，一般认为低于1较为合理 |
| EV/EBITDA | 企业价值(市值+净债务)除以税息折旧摊销前利润，比P/E更能排除资本结构差异的干扰 |
| FCF（自由现金流） | 公司经营赚到的现金，减去维持/扩张业务所需花掉的钱(资本开支)之后，真正能自由支配的现金 |
| FCF Yield（自由现金流收益率） | 自由现金流除以市值，类似于把公司当"债券"看它的"票面利率" |
| Capex（资本开支） | 公司花钱建厂房、买服务器、建数据中心这类长期投入，不是当期就能花完变利润的钱 |
| ROIC（投入资本回报率） | 公司每投入1块钱资本（不管是借的还是自己的），能赚回多少钱，越高说明生意越好 |
| ROE（净资产收益率） | 公司用股东的钱（不含借的钱），能赚回多少利润的比率 |
| WACC（加权平均资本成本） | 公司借钱+发股票融资的综合成本，是判断"赚的钱值不值得投"的及格线，ROIC要高于WACC才算真赚钱 |
| DCF（现金流折现估值法） | 把公司未来能赚到的所有现金，按一定折扣率"折算"成今天的价值，从而估算这家公司"到底值多少钱" |
| SOTP（分部加总估值法） | 把一家公司拆成几块业务分别估值，再加总，比如把谷歌拆成"广告""云""Waymo"分别算钱再加起来 |
| DuPont分析（杜邦分析） | 把ROE拆解成"赚钱能力(净利率)×周转效率(资产周转率)×杠杆水平(权益乘数)"三部分，看清楚利润到底从哪来 |
| Backlog（未确认收入储备/合同储备） | 已经签了合同但还没有确认为收入的未来收入，backlog越大说明未来收入越有保障 |
| SBC（股权激励费用） | 公司用股票（而非现金）付给员工的薪酬，会稀释老股东的持股比例 |
| 反垄断救济方案(Remedies) | 法院判定一家公司垄断成立后，要求它采取的"纠正措施"，可能是行为性的（改变做法）也可能是结构性的（强制拆分/剥离业务） |
| DMA（数字市场法案） | 欧盟专门针对大型科技平台的监管法规，对"看门人"平台施加额外的合规义务 |
| 13F | 大型机构投资者(管理规模超1亿美元)必须按季度向SEC披露持仓的文件，是观察"聪明钱"动向的重要窗口 |
| Short Interest（做空持仓/空头持仓） | 市场上被卖空、押注股价下跌的股票数量，比例越高代表看空情绪越浓 |
| Days to Cover（回补天数） | 按照平均每日成交量计算，空头需要多少天才能全部买回股票平仓，天数越少说明逼空风险越低 |
| Implied Volatility 隐含波动率(IV) | 期权市场价格反推出的、市场对该股票未来波动幅度的预期，越高代表市场预期波动越剧烈 |
| TPU（张量处理单元） | 谷歌自主研发设计的AI专用芯片，用来替代/补充英伟达GPU进行AI模型的训练和推理 |
| IaaS / PaaS | 基础设施即服务/平台即服务，云计算的两种主要商业形态，简单说就是"租服务器"和"租开发工具" |
| ARR（年化经常性收入） | 把当前的收入水平按年化换算，常用于衡量订阅制/云服务类公司的收入规模，比如"Anthropic年化收入$65B" |
| Robotaxi（无人驾驶出租车） | 没有人类司机、完全由AI系统驾驶运营的出租车服务，Waymo是该领域的代表性公司 |
| Zero-click Search（零点击搜索） | 用户在搜索结果页直接获得答案（比如AI摘要），不再点击进入具体网站的搜索行为 |
