## 【新手第一课】在读正文之前，你需要知道的三件事

1. **什么是"光刻机"，为什么这家公司这么重要？** 造芯片就像用"极其精密的高级打印机"把电路图案"印"在硅片上，这台"打印机"就是光刻机（lithography machine）。芯片越先进（越省电、算力越强），需要印的电路线条就越细，所需要的光源波长就越短、精度要求就越高。ASML是全世界唯一能造出使用"极紫外光"（EUV，波长13.5纳米，比可见光短几十倍）光刻机的公司——没有它的机器，全世界都造不出苹果、英伟达、AMD等公司设计的最先进芯片。
2. **它不是靠"打败对手"赚钱，而是没有对手。** 本报告后面会反复出现"ASML没有直接竞争对手"这句话——这不是夸张，而是行业事实：EUV光刻机领域，ASML市场份额就是100%。所以本报告在做"同行对标"时，对标的意义不是"份额竞争"，而是用应用材料（Applied Materials）、泛林集团（Lam Research）、科磊（KLA）、东京电子（Tokyo Electron）等半导体设备同行来衡量"整个设备行业的估值水位和景气度"，以及用台积电、三星、英特尔等下游客户的资本开支来预判ASML的订单趋势。
3. **为什么"荷兰-美国-中国"这三个词会反复出现？** ASML总部在荷兰，其最先进的设备涉及美国的技术（美国的出口管制法律可以延伸管辖使用美国技术的外国产品），而中国大陆曾经是ASML最大或第二大的收入来源地之一。这三方之间的政治博弈，直接决定了ASML能不能把机器卖给中国客户、能卖多先进的机型——这是贯穿全篇最重要的风险变量，我们把它放在第六章专门讲清楚。

**【小白导读】** 这一章回答的问题很简单：ASML是干什么的、怎么走到今天这一步的、以及市场应该把它当成一家什么样的公司来看待。

**1.2 发展历史（关键节点）**

- **1984年**：由飞利浦（Philips）与ASM International合资成立，早期条件简陋（媒体常用"漏雨的棚屋"形容其初创办公环境）（来源：Techzine，2026）。
- **1995年**：在阿姆斯特丹和纳斯达克同步上市，上市时估值约5亿美元（来源：Pestel-analysis整理，2026）。
- **2000年代初**：飞利浦逐步退出持股，ASML走向完全的机构化股权结构（来源：同上）。
- **2012年**：一个对理解ASML商业模式至关重要的历史事件——英特尔、台积电、三星三大下游客户联合入股ASML，共同出资支持EUV技术的研发（这也是理解ASML为何能在EUV上遥遥领先的关键：连竞争对手的客户都要"众筹"帮它把技术做出来，因为整个行业都离不开它）（来源：Pestel-analysis/MatrixBCG整理，2026）。
- **2013-2024年**：Peter Wennink任CEO（此前自1999年起任CFO，曾为德勤合伙人，专长半导体设备行业审计），任内公司股价上涨逾10倍，成长为欧洲市值最大的科技公司（来源：DatacenterDynamics，2024；Wikipedia整理）。
- **2019年**：ASML在美国法院就商业机密盗窃案获判8.45亿美元赔偿（被告为与前员工相关的Xtal Inc.，详见第六、十二章地缘政治与新闻章节）（来源：多方媒体整理）。
- **2023-2025年**：在美国政府施压下，荷兰政府多次收紧对华出口管制（详见第六章），ASML中国区收入占比经历"先冲高后回落"的剧烈波动。
- **2024年4月**：Christophe Fouquet接任CEO，此前历任应用材料、科磊市场与产品管理岗位，2008/2009年加入ASML，2013年起任应用事业部EVP，2022年任首席商务官（来源：btw.media、DatacenterDynamics，2024）。
- **2024年11月14日**：召开Investor Day，首次给出2030年收入指引区间€440亿-€600亿（来源：ASML官方新闻稿及TechInsights整理，2024）。
- **2026年1-7月**：受AI算力需求驱动，ASML连续两次上调2026年全年指引（从最初约€30-40B区间，到2026年1月上调至约€36-40B，再到2026年7月Q2财报时上调至€43-45B），详见第九、十一章（来源：ASML各季度财报新闻稿，2026）。

**1.3 公司定位**：市场把ASML定价为"成长股+周期股"的混合体——由于其收入高度依赖下游晶圆厂资本开支（强周期性），历史上市盈率波动极大（十年区间36-88倍，见第十三章）；但由于其技术垄断地位和AI驱动的长期结构性成长叙事，近两年市场越来越倾向于给予其"稀缺成长股"的估值溢价。管理层自身的叙事也从"半导体设备供应商"逐渐转向"AI基础设施皮下之王"（enabler of the AI era）——这与当前收入结构（仍主要靠卖光刻机及服务）基本一致，但长期增长依赖的AI驱动逻辑尚需未来几年数据验证。

**1.4 股权结构**：ASML实行"一股一票"制度，不存在双重股权结构或创始人超级投票权；据MarketScreener/Tickergate等多方数据整理，截至2026年，最大机构股东为Vanguard Group（约8.9%）与Capital Group（约7.4%），其余为Fisher Investments、Capital World Investors等长仓机构投资者，公司自由流通股占比约98%（来源：MatrixBCG/Pestel-analysis整理，2026）。管理层直接持股比例较低（属于典型的"专业经理人+机构股东"治理结构），股东利益绑定主要通过股权激励计划实现（详见第七、八章）。

**【本节结论】** ASML的历史本质上是一部"用30年时间把物理极限往前推"的故事：从飞利浦孵化的小作坊，到被自己最大的客户联合入股续命研发EUV，再到今天成为全球AI算力扩张周期中"卖铲子的人"。它的股权结构干净、透明，没有创始人控制或治理黑洞，这为后续章节的护城河和估值分析提供了一个相对"干净"的起点——它的核心风险不在公司治理，而在技术周期和地缘政治。

## 第二章：行业分析——它所在的赛道值不值得看？

**【小白导读】** 这一章要回答：芯片设备这个行业本身是不是一个好赛道？是持续增长还是快到头了？会不会突然被别人抢生意？

**【专业深挖】**

**2.1 行业空间**：据SEMI（国际半导体产业协会）2025年12月发布的年终预测，全球半导体制造设备销售额预计2025年达到$1,330亿（同比+13.7%），2026年预计达$1,450亿，2027年预计达$1,560亿；其中晶圆制造设备（WFE）细分市场2025年预计$1,157亿（+11.0%），主要由AI相关的DRAM/HBM（高带宽内存）投资拉动，2026年WFE预计再增长9.0%，2027年增长7.3%（来源：SEMI新闻稿，2025-12）。据WSTS（世界半导体贸易统计组织）数据，全球半导体市场规模2025年预计达$7,720亿（+22%），2026年预计增长超过25%，达到约$9,750亿（来源：WSTS新闻发布，2026）。ASML管理层在2024年11月Investor Day上给出的长期展望是：全球半导体市场规模到2030年将超过1万亿美元，2025-2030年复合增速约9%（来源：ASML Investor Day新闻稿整理，2024-11-14）。

**2.2 行业驱动因素**：当前最核心的驱动力是AI算力需求——大语言模型训练与推理对先进逻辑芯片和高带宽内存（HBM）的需求呈爆发式增长，直接推升台积电、三星、SK海力士等客户的资本开支（详见2.6及第十二章）。此外，先进封装、2nm以下制程节点的产业化，以及智能手机/PC换机周期的边际改善，也是驱动因素（来源：多方行业新闻综合，2026）。

**2.3 行业周期**：半导体设备行业历史上是强周期行业，与晶圆厂资本开支周期高度相关，过去经历过多轮"扩产-消化-再扩产"波动（如2022年因消费电子疲软导致的下行周期）。当前行业处于由AI资本开支驱动的新一轮上行周期中，且这轮周期的独特之处在于：驱动力并非消费电子的传统换机周期，而是数据中心/AI基础设施的结构性资本开支扩张，因此本轮周期的持续性和幅度存在较大不确定性，是市场争议的焦点（来源：SemiconAlpha、EBC Financial Group等行业评论综合，2026）。

**2.4 竞争格局**：光刻设备细分市场高度集中，EUV领域ASML市场份额为100%（无竞争对手），整体光刻设备市场份额约90%（来源：多方行业分析综合，包括Yahoo Finance"ASML沉默的垄断者"专题、The Generalist深度报告，2026）。Nikon、Canon仅在成熟制程的KrF/i-line光刻机领域占有份额，未涉足EUV技术路线（来源：同上）。半导体设备行业整体（涵盖刻蚀、薄膜沉积、量测检测等其他工序设备）则由应用材料、泛林集团、东京电子、科磊与ASML五家公司主导（"设备五巨头"），但彼此在细分工序上并不直接竞争——应用材料在薄膜沉积/材料工程领域领先，泛林在刻蚀领域领先，科磊在量测检测领域领先，东京电子在刻蚀/涂胶显影领域领先，而ASML在光刻领域处于事实垄断地位（来源：Accio/MatrixBCG行业格局整理，2026）。

**2.5 波特五力评分（1-10分，10分表示对ASML最有利）**

| 五力维度 | 评分 | 依据 |
|---|---|---|
| 现有竞争者威胁 | 10/10（几乎不存在） | EUV领域ASML市场份额100%，Nikon/Canon未涉足EUV |
| 新进入者威胁 | 9/10 | 30年技术积累+约90亿美元研发投入构筑的壁垒，几乎不可能被复制（来源：The Review/StrangeVC深度分析，2026） |

| 供应商议价权 | 5/10 | ASML对Zeiss（蔡司，光学镜头独家供应商）等关键零部件供应商存在依赖，供应商议价权中等偏高，对ASML构成一定成本/交期约束（详见第六章） |
| 买方议价权 | 4/10 | 台积电、三星、英特尔等下游客户体量巨大且集中度高，对交付节奏和价格有一定议价空间，但因ASML产品不可替代，议价权总体有限 |

**2.6 区域市场拆分**：需求端高度集中于东亚——台湾（台积电）、韩国（三星、SK海力士）是最大的两个采购地区，中国大陆此前是重要收入来源（2025年占比33%），但受出口管制影响预计2026年降至约20%（来源：ASML季度财报及Caixin Global整理，2026-01），美国（英特尔）占比相对较小但战略意义重大（美国"芯片法案"及国内产能扩张诉求）。日本作为光刻设备的传统另一极（Nikon/Canon总部所在地），目前在先进制程领域的设备采购份额较小。

**【本节结论】** 半导体设备行业目前处于近十年来最强劲的一轮景气周期中，核心驱动力从传统消费电子切换为AI基础设施资本开支，行业规模的官方预测（SEMI/WSTS）持续被上调，这是一个总量仍在扩张、但集中度极高、赢家已经确定的赛道——ASML作为光刻环节的唯一供应商，是这轮周期确定性最高的受益者之一，但正因为如此，"行业好不好"这个问题对ASML而言几乎已经不是核心矛盾，真正的核心矛盾在于地缘政治（第六章）和当前估值是否已经price in了过多乐观预期（第十三章）。

## 第三章：商业模式——它到底怎么赚钱？

**【小白导读】** 这一章讲清楚ASML的钱从哪儿来：卖设备，还是卖服务？谁在买？为什么非买不可？

**【专业深挖】**

**3.1 收入结构**：ASML收入主要分为两大块：① 系统销售（System Sales，即卖光刻机整机及DUV/EUV设备），② 装机后管理服务收入（Installed Base Management，IBM，包括设备升级、备件、维保服务）。以2026年第二季度为例：总净销售额€93亿，其中系统销售€66亿（含EUV系统销售€38亿、非EUV系统销售€28亿），装机后管理服务销售€28亿（占比约30%，环比该季度超指引€3亿）（来源：ASML Q2 2026财报新闻稿，2026-07-15）。装机后服务收入具有更强的经常性收入属性（设备一旦装机，后续几十年都需要备件和软件升级服务），是公司收入结构中"压舱石"的部分。收入的货币结构上，公司主要以欧元记账，但下游客户遍布全球（美元、新台币、韩元、人民币计价的订单均存在），存在实质性汇率敞口（详见第六、九章）。

**3.2 核心业务模式**：ASML本质上是"卖硬件设备+长尾服务"模式，不同于订阅制软件公司，其收入更接近"卖大型资本品+售后服务"（类似飞机制造商卖飞机+提供维保）。核心变现方式：整机销售（一次性但金额巨大，单台EUV机型报价可达约€2亿-€4亿量级，High-NA机型报价更高）+设备生命周期内的持续服务收入。

**3.3 产品组合**：核心产品包括NXT系列DUV浸没式光刻机（成熟产品，覆盖大部分成熟制程需求，也是当前对华出口管制的焦点，见第六章）、NXE系列EUV光刻机（增长产品，先进制程刚需）、以及最新一代EXE系列High-NA EUV光刻机（战略性下一代产品，目前处于客户导入验证阶段，详见第四、十二章）。

**3.4 客户与需求**：ASML的客户集中度天然很高——全球能采购最先进光刻机的客户就是台积电、三星、SK海力士、英特尔等屈指可数的几家逻辑芯片代工厂/存储芯片厂商。据2026年一季度数据，韩国（三星为主）一度占到该季度系统销售额的45%（三星扩大10nm以下EUV产能，据报道一次性下单约20台EUV系统），凸显出订单结构在单一大客户间的高波动性（来源：quantumrun Statistics整理，2026）。客户粘性极高：一旦某个制程节点的产线选定使用ASML设备，转换供应商的技术风险和时间成本极高（详见第五章）。具体各大客户占ASML总收入的精确占比，官方财报未按客户单独披露，为避免误导，此处标注为**[数据待查/公司未按单一客户披露具体收入占比]**，仅可通过区域数据间接推断（详见第九章区域销售数据）。

**3.5 成本结构**：主要成本为原材料与外购精密部件（如蔡司光学系统、高精度机械零部件）、研发投入（2025年研发费用€46.99亿，占收入比重约14.4%）（来源：ASML相关财报整理，2026）、以及人工成本（约4.8万名员工，多为高端工程技术人才，人力成本较高但人均产出效率极高）。

**3.6 利润模型**：装机后管理服务业务毛利率显著高于系统销售业务（服务类收入通常有更高定价权和更低边际成本），是拉动公司整体毛利率提升的重要因素。2026年公司管理层指引显示，随着EUV尤其是High-NA EUV占比提升以及规模效应显现，全年毛利率指引已上修至54%-56%（较2025年全年52.8%明显提升）（来源：ASML Q2 2026财报，2026-07-15）。

**3.7 商业模式质量**：收入稳定性方面，尽管单季度受大额订单确认节奏影响波动较大（如2024年Q3订单环比骤降53%引发市场恐慌，详见第十二章），但从跨年度维度看，公司收入呈现清晰的结构性增长趋势；网络效应不显著（ASML不是平台型公司），但存在强规模效应（研发投入的固定成本被摊薄）与极强定价权（technology moat带来的溢价能力）。

**【本节结论】** ASML的商业模式简单但极难复制：卖一台价值数亿欧元的"印钞机"给全世界仅有的几个买家，然后靠几十年如一日的服务收入持续变现。这种模式的脆弱点在于订单确认的季度节奏波动大（容易造成市场对短期数字的过度反应），但长期看，其"卖设备+服务"的组合正在向更高毛利率结构演进——这是支撑公司利润率长期扩张叙事的核心证据。

**4.5 产品周期**：当前正处于"三代产品并行"的关键窗口期——DUV仍是走量主力（尤其对成熟制程和中国市场），Low-NA EUV是当前先进制程的现金牛，High-NA EUV是决定2028-2031年增长曲线的关键新品，其商业化节奏（尤其是台积电2030年才导入的时间表）意味着公司未来3-4年的增长仍主要依赖现有Low-NA EUV产能爬坡和DUV需求，而非High-NA的规模化贡献——这是市场对公司中期成长性存在分歧的技术性根源。

**【本节结论】** ASML的产品竞争力不是来自单一"黑科技"，而是极紫外光源、精密光学、计算光刻三个极难的工程问题被同时解决后形成的系统性壁垒；High-NA EUV是公司下一代增长引擎，目前英特尔进度最快但订单体量有限，而台积电、三星（体量最大的两个客户）导入时间表分别在2030年和2028年，这意味着市场如果对2027-2029年的增长预期过度依赖"High-NA放量"叙事，存在时间线预期差风险，真正的验证节点应关注2028年三星DRAM导入和更早的英特尔量产良率数据。

## 第六章：地缘政治与供应链韧性（本报告重点章节）

**【小白导读】** ASML是全球半导体供应链里最典型的"单点故障"公司——它一家公司如果出了问题（无论是技术、产能还是政治原因），全世界的先进芯片生产都会受影响。正因如此，美国、荷兰、中国三方近几年围绕"能不能把光刻机卖给中国"展开了持续的博弈，这一章要把这件事的来龙去脉和对公司业绩的实质影响讲清楚。

**【专业深挖】**

**6.1 地理集中度风险**：ASML总部、核心研发及绝大部分先进制程设备的最终总装均集中于荷兰Veldhoven，属于高度地理集中的生产模式，一旦荷兰本土发生极端事件（自然灾害、能源危机、政治动荡），全球先进芯片供应链将面临系统性冲击（本项为情景假设，非当前已发生事件）。

**6.2 出口管制历史沿革（关键时间线）**：

| 2023年6月30日 | 荷兰政府发布《先进半导体制造设备法令》（基于欧盟两用物项条例第9(1)条），对DUV浸没式光刻机等设备实施出口管制 | 首次正式立法限制 | CNBC，2023-06-30 |

**6.3 中国区收入占比变化趋势（核心财务影响数据）**：
- 2025年全年，中国大陆客户贡献ASML总净销售额的**33%**（来源：MarketWise/多方财报数据整理，2026）。
- 2025年第四季度，中国大陆一度占当季系统销售额的**36%**，但这被普遍解读为"许可证有效期内抢装"的结构性因素，而非需求可持续（来源：quantumrun整理，2026）。
- 2026年第一季度，中国大陆占当季系统销售额骤降至**19%**（来源：quantumrun Statistics，2026）。
- ASML管理层在2026年初已明确指引：预计中国大陆收入占比将从2025年的33%降至2026年全年约**20%**左右（来源：Caixin Global，2026-01-29；MarketWise，2026）。
- 与此同时，韩国（主要为三星EUV扩产）在2026年第一季度一度占系统销售额的**45%**，凸显订单结构正从"中国抢装DUV"转向"韩国/台湾扩产EUV"（来源：quantumrun整理，2026）。

**6.4 供应链多元化进度**：**[数据待查/公开信息有限]**——ASML是否在荷兰以外建立第二总装基地，暂无充分公开披露的具体进展数据，需进一步核实。公司在美国、中国大陆等地设有区域性技术支持与服务中心，但核心研发与总装环节高度集中于荷兰（韦尔多芬）及部分位于美国（康涅狄格州，DUV光源模块）和德国（蔡司光学系统）的关键供应商基地。

**6.5 关键原材料/环节依赖**：ASML对蔡司（Carl Zeiss SMT，德国）的高精度光学镜头系统存在深度且事实上排他性的依赖，对Cymer（美国，ASML于2013年已收购，提供准分子激光光源）等核心零部件供应商也存在技术集中依赖。这种"上游高度集中"的结构意味着ASML自身虽是下游客户眼中的"卡脖子"环节，但其自身也存在被少数几个关键零部件供应商"卡脖子"的潜在风险（尽管Cymer已被收购内部化，风险有所降低）。

**6.6 极端情景假设**：
- **情景A——美国进一步要求荷兰限制DUV浸没式设备对华出口**：据TechPowerUp等媒体报道，美国政府曾考虑进一步限制ASML对华DUV工具出口（来源：TechPowerUp，2026）。若此情景落地，中国区收入占比可能进一步从当前约20%下探至个位数百分比，对应公司整体收入潜在下修幅度需结合具体管制范围测算，目前**[数据待查/管制范围尚未最终明确，无法精确量化]**。

## 第八章：资本配置与股东回报质量

**【小白导读】** 这一章要回答：管理层赚的钱，是在给股东创造价值，还是在浪费钱？

**【专业深挖】**

**8.1 ROIC vs WACC**：采用简化模型估算（方法：ROIC≈净利润/投入资本，投入资本=股东权益+有息负债-现金及现金等价物），以2025财年数据为例：股东权益€196.12亿、有息负债约€27亿、现金及短期投资€133.22亿（来源：ASML 2025年年报相关数据整理，2026），投入资本≈€90亿，净利润€96.09亿，简化ROIC≈**107%**。对比WACC（据Alpha Spread模型：无风险利率3.24%+Beta1.24×股权风险溢价4.3%=股权成本8.57%，结合债务成本3.81%后WACC≈**8.55%**，来源：Alpha Spread，2026），ROIC与WACC利差极为悬殊（约+98个百分点）。需要特别说明：由于ASML净现金规模巨大而有息负债极少，"投入资本"分母天然很小，导致简化ROIC数值显著高于传统重资产行业的"合理"ROIC区间，这本身即是ASML"轻资产、高垄断溢价"商业模式的量化体现，而非计算错误。

**8.2 再投资率与边际回报**：2025年资本开支（含无形资产）约€16.31亿，较2023年的€21.96亿明显下降，同期收入从€275.59亿增至€326.67亿，反映出公司在收入扩张的同时资本开支强度不升反降——即"每多投1欧元资本"带来的边际收入产出效率在持续提升（来源：财报数据整理，2026）。

**【本节结论】** ASML的资本配置整体呈现"轻资本开支、高研发投入、持续加码回购与分红"的健康组合，简化ROIC与WACC之间的巨大利差直接印证了其技术垄断带来的超额经济利润；主要待改进的信息缺口在于股权激励稀释和历史回购精确定价数据的完整披露，但从现有数据看，没有发现管理层存在明显价值毁灭型资本配置行为的证据。

## 第十五章：ESG与监管/合规风险

**【小白导读】】 这一章看的是那些"听起来不是纯财务问题,但真出事会实打实影响公司赚钱能力"的风险,比如数据隐私、反垄断、碳排放、供应链用工合规。

| 术语 | 大白话解释 |
|---|---|
| 光刻机（Lithography Machine） | 造芯片用的"高级打印机"，把电路图案精确"印"到硅片上 |
| EUV（极紫外光刻） | 用波长仅13.5纳米的极短波长光进行曝光的最先进光刻技术，是造最先进芯片的必需设备，全球只有ASML能造 |

| High-NA EUV（高数值孔径EUV） | 下一代更高精度的EUV光刻机，能造出比现在更先进的芯片，目前处于客户导入验证的早期阶段 |
| 净销售额（Net Sales） | 公司卖设备和服务收到的总收入，扣除退货折扣等之后的数字 |
| 毛利率（Gross Margin） | 卖东西赚的钱占收入的比例，越高说明产品定价权和成本控制越好 |
| 净利率（Net Margin） | 最终净利润占收入的比例 |
| ROE（净资产收益率） | 公司用股东的钱能赚回多少比例的利润，越高说明股东的钱"钱生钱"效率越高 |
| ROIC（投入资本回报率） | 公司每投入1块钱资本能赚回多少钱，越高说明生意本身越好 |
| WACC（加权平均资本成本） | 公司借钱和用股东的钱这两种"融资成本"的加权平均值，是判断投资是否划算的门槛利率 |
| FCF（自由现金流） | 公司经营赚到的钱扣除必要的资本开支后，真正能自由支配（分红、回购、还债）的现金 |
| EV/EBITDA | 企业价值除以息税折旧摊销前利润，一种常用的估值倍数，剔除了资本结构和折旧政策差异的影响 |
| DCF（现金流折现估值法） | 把公司未来能赚的钱按一定折扣率换算成"今天值多少钱"的估值方法 |
| 净现金 | 公司账上的现金比它欠的债还多，说明财务非常安全 |
| 护城河（Moat） | 一家公司能长期抵御竞争、维持高利润的核心优势 |
| 事实垄断（De Facto Monopoly） | 不是靠打压对手，而是因为技术门槛太高，市场上根本没有能打的竞争对手 |
| Bookings（订单/在手订单） | 客户下的、还没确认收入的合同订单金额，是判断未来业绩的领先指标 |
| 出口管制（Export Control） | 政府限制某些高科技产品出口到特定国家/地区的法律政策 |
| 13F | 美国大型机构投资者按季度必须向SEC披露持仓明细的监管文件 |
| 做空比例（Short Interest） | 市场上做空该股票的股数占可交易流通股的比例，越高说明看空该股票的资金越多 |
| 隐含波动率（Implied Volatility, IV） | 期权市场对该股票未来波动幅度的预期定价，越高说明市场预期波动越剧烈 |
| Put/Call Ratio（看跌看涨比率） | 看跌期权与看涨期权的成交量或持仓量之比，用于判断市场情绪偏向 |
| SBC（股权激励费用） | 公司用股票（而非现金）支付给员工的薪酬，会稀释现有股东的持股比例 |
| SOTP（分部加总估值法） | 把公司不同业务板块分开单独估值再加总，得到整体合理市值 |
| 杜邦分析（DuPont Analysis） | 把ROE拆解成净利率×资产周转率×权益乘数三部分，帮助理解利润是靠什么驱动的 |
| Beta（贝塔系数） | 衡量个股相对大盘波动的敏感程度，大于1说明比大盘波动更剧烈 |
