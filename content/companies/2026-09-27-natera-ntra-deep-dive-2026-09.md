## 第一章：公司背景——这家公司是谁？

**【小白导读】**
Natera 是一家美国的"基因检测"公司。你可以把它理解成一个专门帮医生"看血液里的DNA线索"来做诊断的实验室服务商：孕妇验血能提前查出胎儿是否有唐氏综合征等染色体异常，癌症病人手术后验血能查出体内是否还有癌细胞在悄悄复发，做了器官移植的病人验血能查出身体是否在排斥新器官。这些检测背后共同的科学基础叫"液体活检"（Liquid Biopsy——不用开刀取组织，只抽一管血就能拿到基因信息的检测技术），公司靠向医院、医生和保险公司收取检测服务费赚钱。

## 第二章：行业分析——它所在的赛道值不值得看？

**【小白导读】**
Natera所在的赛道叫"液体活检"（Liquid Biopsy）——传统上要诊断癌症、监测癌症复发,常常需要开刀取组织样本（活检），而液体活检只需要抽血就能从血液里游离的DNA片段（这些DNA片段叫"循环肿瘤DNA"，英文缩写ctDNA——癌细胞死亡后释放到血液里的DNA碎片，携带癌症的基因印记）中读出癌症的信息。这个赛道被认为是未来十年精准医疗最大的增长点之一，因为它比开刀活检更便宜、更安全、可以反复做（方便追踪病情变化）。

**【专业深挖】**

### 2.1 行业空间
液体活检全球市场规模的第三方估算存在较大分歧（不同研究机构方法论不同），需要交叉呈现而非单一数字：
- Research and Markets（2025年更新）：预测到2030年市场规模持续扩张（具体基数[数据待查]）
- Grand View Research：全球液体活检市场2025年约为USD 81.4亿，预计2030年达到USD 151亿，CAGR约13.2%（来源：Grand View Research，2025-2026年报告页面）
- Precedence Research：2025年市场规模约USD 63亿，预计2035年达到USD 199亿，CAGR约12.1%（来源：Precedence Research，2025-2026）
- 另一分析给出2025年USD 136亿、2033年USD 326亿、CAGR约11.5%的口径（来源同类第三方市场研究平台，具体机构名称[需进一步核实]）
- 还有口径给出2025年USD 82.0亿、2035年USD 334.5亿、CAGR约15.0%的更激进预测

**结论性判断**：尽管绝对数字口径不一致（基数从$63亿到$136亿不等，这本身反映出液体活检作为新兴市场缺乏统一的行业分类标准），但**所有第三方机构一致认为该行业CAGR在11.5%-15%之间**，显著快于整体医疗诊断行业平均个位数增速，且**MRD（微小残留病灶）检测被普遍认为是液体活检内部增长最快的子赛道**（来源：多方市场研究综合，2025-2026）。Natera的Signatera产品线正处在这个最快增长的子赛道核心位置。

### 2.2 行业驱动因素
1. **医保覆盖持续扩大**：这是过去两年液体活检行业最重要的结构性驱动力。CMS（美国医疗保险和医疗补助服务中心）通过MolDX项目不断为MRD检测建立新的本地覆盖决定(LCD)，覆盖病种从结直肠癌逐步扩展到乳腺癌、膀胱癌、卵巢癌、肺癌乃至泛癌种免疫治疗监测（详见第十一、十六章）——每新增一个覆盖病种，都直接打开新的可报销市场
2. **NCCN临床指南采纳**：2026年Signatera在膀胱癌治疗指南中获得NCCN Category 1级别推荐（循证等级最高），意味着使用该检测已成为"标准诊疗路径"的一部分，而非可选项（来源：Natera 2026年Q2财报新闻稿）
3. **测序成本持续下降**：下一代测序(NGS)成本的长期下降曲线，是整个行业毛利率结构性改善的底层技术驱动力
4. **精准医疗/个体化治疗理念的普及**：肿瘤治疗从"一刀切"化疗转向基于分子标志物的个体化方案，ctDNA检测是这一趋势的关键工具
5. **人口老龄化与癌症发病率**：全球癌症新发病例的长期增长趋势为整个肿瘤诊断赛道提供了基础性的量增逻辑

### 2.3 行业周期
液体活检/分子诊断行业总体呈**非强周期、防御性**特征——医疗支出受经济周期影响较小。但行业存在一种特殊的"政策周期"：Medicare LCD覆盖决定、FDA监管规则（如LDT新规的推出与撤销）会带来阶段性的政策不确定性，这是比宏观经济周期更重要的行业周期变量。当前（2026年）行业正处于"监管尾部风险刚被消除（LDT新规撤销）+ 医保覆盖持续扩容"的上行窗口期。

### 2.4 竞争格局
液体活检/肿瘤MRD检测赛道当前呈现"一超多强"格局：Natera凭借Signatera在MRD检测领域收入规模最大、检测量增速最快（2026Q2同比+57.2%），但Guardant Health（Guardant Reveal）与Exact Sciences（Oncodetect，2025年4月上市，2026年推出下一代全基因组版本MAESTRO）正在加速追赶，行业尚未形成寡头垄断格局，价格战/份额战风险客观存在（详见第十八章风险分析）。同时，Invitae于2024年破产、其资产被Labcorp收购的行业事件，说明分子诊断行业资本消耗巨大、并非所有参与者都能撑到规模化盈利的那一天——这既是Natera的护城河佐证（活下来的少数玩家之一），也是行业出清尚未完成的信号。

| 供应商议价权 | 6/10 | 高度依赖Illumina等测序平台供应商，测序试剂/仪器成本对毛利率有直接影响，属于中高供应商议价权 |
| 买方（医保/患者）议价权 | 7/10 | CMS/商业保险公司对检测报销费率(ASP)有决定性影响，是行业最大的外部变量，买方议价权评分较高 |

### 2.6 区域市场拆分
Natera当前收入绝大部分来自美国本土市场（因为Medicare/商业保险报销体系是收入核心驱动力）。国际化进展体现为：2026年Signatera先后获得日本PMDA膀胱癌伴随诊断批准与欧盟IVDR认证（来源：Natera 2026年Q2财报新闻稿），标志着国际化从"临床合作"阶段迈入"商业化准入"阶段，但目前国际收入占比[数据待查/不适用]——公司未在最新财报中单独披露美国本土 vs. 海外收入分拆比例。

**【本节结论】**
液体活检行业是一个"故事够大、证据够硬"的赛道——CAGR预期区间虽然因统计口径不同而有分歧（11.5%-15%），但方向性判断高度一致：这是未来十年医疗诊断领域增长最快的子赛道之一，而MRD检测又是其中增长最快的部分。行业当前最重要的边际变量不是需求端（需求已被验证），而是"医保覆盖扩容速度"与"竞争格局是否会演变为价格战"这两个供给侧/政策侧变量，这也是评估Natera投资价值时必须持续跟踪的两个核心指标（详见第二十章）。

## 第三章：商业模式——它到底怎么赚钱？

**【小白导读】**
Natera的赚钱方式很直接：每做一次检测，向医院、医生或者保险公司收一笔"检测服务费"。它不是靠卖设备、也不是靠订阅收费，而是纯粹的"检测服务(Testing-as-a-Service)"模式——类似于医院化验科的商业化外包版本，但技术门槛和专利壁垒高得多。

**【专业深挖】**

### 3.1 收入结构
Natera收入结构高度集中——产品（检测服务）收入占总收入的**99.5%以上**：2025年产品收入$22.958亿 / 总收入$23.061亿 ≈ 99.6%（来源：Natera FY2025财报新闻稿，2026年2月）。这意味着公司几乎没有"许可授权收入""广告收入"等其他收入形式的稀释，收入质量单一但透明，投资者可以直接把"检测量×平均检测费率(ASP)"当作核心收入驱动力公式来理解。公司未在最新财报中单独披露分产品线（Signatera/Panorama/Horizon/Prospera）或分地区的收入占比明细，仅披露"肿瘤检测(oncology)"与"总检测量"两个维度的量的数据（详见第九章），分产品线的精确收入贡献占比**[数据待查/不适用]**。

### 3.2 核心业务模式
按业务线可将Natera收入来源归纳为四大类，全部是"按次检测服务费"模式，没有订阅制或平台抽成模式：
1. **女性健康（Women's Health）**：Panorama（无创产前检测NIPT）+ Horizon（携带者筛查）——面向孕产/备孕人群
2. **肿瘤学（Oncology）**：Signatera（个体化肿瘤ctDNA MRD检测）——面向已确诊癌症患者的术后监测、辅助治疗决策、复发监测、免疫治疗响应监测
3. **器官健康（Organ Health）**：Prospera——面向器官移植患者的排斥反应监测
4. **药物研发服务（Pharma/Biopharma）**：向药企提供伴随诊断/临床试验патients分层服务（Signatera作为FDA批准的伴随诊断产品，可协助药企的临床试验设计与患者入组）

### 3.3 产品组合
| 产品 | 所属业务线 | 生命周期阶段 | 2026Q2趋势 |
|---|---|---|---|
| Panorama | 女性健康 | 成熟期，持续技术迭代（如提升低胎儿分数下的检出率） | 增强版实现100%检出21三体（低胎儿分数场景），无效检出率仅0.5%（来源：Natera 2026Q2财报） |
| Horizon | 女性健康 | 成熟期 | 数据未单独披露 |
| Signatera | 肿瘤学 | 高速放量期（核心增长引擎） | 肿瘤检测量同比+57.2%，MRD临床检测量283K，同比+56%（来源：同上） |
| Prospera | 器官健康 | 早中期放量，受益于2026年8月30日起生效的新Medicare LCD | 管理层预期新LCD将带动2026下半年检测量增长（来源：同上） |

### 3.4 客户与需求
Natera的直接客户是**开具检测处方的医生/医院系统**，最终付费方是**患者的医疗保险（Medicare、商业保险）或患者自付**。客户集中度层面，公司未披露前5/前10大客户占比（因为客户高度分散在全美各医院/诊所网络中），**客户集中度风险总体较低**，但"付费方集中度"风险较高——Medicare/CMS作为单一最大付费方，其覆盖政策变化对收入影响巨大（详见第十五、十八章）。客户粘性来源于：一旦某医院/肿瘤科室将Signatera纳入标准诊疗路径（尤其是获得NCCN Category 1推荐后），转换到竞品的临床验证成本和医生行为惯性成本都很高。

### 3.5 成本结构
主要成本构成为：测序试剂耗材、测序仪器折旧摊销（依赖Illumina平台）、实验室人工、样本物流。随着检测量规模化，单位检测成本持续下降，是毛利率从2022年44.4%提升到2025年64.7%的核心解释（详见第九章）。

### 3.6 利润模型
分产品线毛利率**[数据待查/不适用]**——公司未拆分披露。但可以合理推断：Signatera作为高单价（ASP约$1,275，目标成熟期ASP $2,000，来源：2026Q2财报电话会议）、高增速产品，边际毛利率应显著高于成熟期的Panorama/Horizon（NIPT/携带者筛查是充分竞争、价格透明度更高的成熟市场）。管理层长期目标是将Signatera平均检测费率(ASP)从当前约$1,275提升至约$2,000的"成熟期"水平，这本身就是驱动整体毛利率结构性上行的关键假设（详见第十六章）。

### 3.7 商业模式质量
- **收入稳定性**：中高——医保覆盖决定一旦做出，通常具有较强的持续性（不会轻易撤销已生效的LCD），但存在覆盖费率被重新谈判下调的风险
- **复购率/重复检测率**：高——MRD监测、器官移植监测本质上是需要"反复检测"的临床场景（每隔几个月复查一次），这是比NIPT（一次性检测，一个孕期只做一次）更好的商业模式特征
- **网络效应**：中等——检测量越大，公司积累的基因组数据库越丰富，理论上有助于改进算法和临床证据积累，形成一定的数据网络效应，但不是严格意义上的双边网络效应
- **规模效应**：强——毛利率提升曲线已经验证了显著的规模效应
- **品牌溢价/定价权**：中高——在NCCN指南获得Category 1推荐后，定价权有实质性提升（详见第十六章）

**【本节结论】**
Natera的商业模式本质上是"检测量×检测费率"的乘法模型，而这个模型目前处于"分子（检测量）高速增长+分母端（单位成本）持续下降+费率(ASP)结构性提升"三重共振的黄金窗口期。这种模式的最大特点是收入质量高（几乎全部是核心检测服务收入，无杂质收入），但也意味着公司几乎没有第二增长曲线的"缓冲垫"——一旦Medicare报销政策或竞争格局出现不利变化，收入增长引擎会直接失速，没有其他业务线可以对冲。

## 第四章：产品与技术——它的产品强在哪里？

**【小白导读】**
这一章要回答：Natera的检测技术是不是真的比竞争对手强,还是只是运气好抢到了先发优势。

**【专业深挖】**

### 4.1 核心产品矩阵

| 产品名称 | 面向客户 | 收入贡献 | 增速（最新季度） | 生命周期阶段 |

### 4.2 产品竞争力
Signatera的核心技术差异化在于"肿瘤个体化定制(tumor-informed)"方法——先对患者的肿瘤组织样本做全外显子/全基因组测序，识别出该患者肿瘤特有的体细胞突变位点，再针对这些个体化位点设计定制化的ctDNA检测panel，从而实现远超"通用型panel"检测方案的灵敏度。这一技术路线的证据是：2026年公布的迄今最大规模肺癌MRD研究（覆盖超过1,100名I-III期可切除非小细胞肺癌患者）为其临床价值提供了循证支持（来源：Natera 2026年Q2财报新闻稿及相关新闻报道）。竞争对手Exact Sciences的Oncodetect同样采用tumor-informed技术路线（最多追踪200个ctDNA变异位点），而2026年即将推出的下一代MAESTRO全基因组版本号称可追踪多达5,000个患者特异性变异位点、检测限低于百万分之一（来源：Exact Sciences官网新闻稿，2025年）——这意味着**Signatera的技术领先窗口正在被竞争对手快速缩小**，技术代际竞赛仍在持续，尚未有一方形成决定性代际领先。

### 4.3 技术路线
Natera选择的"个体化定制(tumor-informed) + 全基因组/全外显子信息指导设计"技术路线，相对于Guardant Health等采用的"固定panel(tumor-naive)"路线，理论上灵敏度更高但检测周期更长、成本结构更复杂（需要先获取并测序肿瘤组织样本）。这一路线已经过多年临床验证并获得NCCN Category 1推荐，可视为已被市场充分验证的技术路径。

### 4.4 研发能力
2025年研发费用为$6.241亿，较2024年的$4.041亿大幅增长54.5%（来源：Natera FY2025财报新闻稿），研发费用率（R&D/总收入）约为27.1%（2025年），显著高于多数成熟诊断公司，反映公司仍处于产品管线快速扩张、临床证据持续积累的投入期。核心专利数量、技术团队具体背景等细节**[数据待查/不适用]**，但从专利诉讼记录看（详见第十二、十五章），Natera持有的核心专利组合具备实质性法律价值——2024年陪审团曾认定CareDx侵犯其专利并判赔$9,630万（尽管后被推翻，仍说明专利本身的有效性得到过司法认定）。

### 4.5 产品周期
公司不存在"过度依赖单一产品"的产品老化风险，因为四条产品线（Panorama、Horizon、Signatera、Prospera）分处不同生命周期阶段，形成了"成熟现金流业务（女性健康）+ 高速增长引擎（Signatera）+ 早期放量业务（Prospera）"的组合结构，这本身是一种产品周期风险对冲。但需要注意的是，公司当前收入增长的绝大部分边际贡献来自Signatera一条产品线，如果Signatera放量不及预期，其余产品线的成熟期特征意味着难以填补增长缺口。

**【本节结论】**
Natera的产品技术实力是真实且经过临床与商业双重验证的（NCCN推荐、FDA伴随诊断批准、大规模临床研究数据），但技术领先优势并非牢不可破的代际差距，而是"目前仍然领先，但竞争对手正在快速追赶"的状态。这意味着公司必须持续加大研发投入（且研发费用率已经处于高位）才能维持技术领先地位，这是理解其未来毛利率/费用率平衡的重要背景。

## 第六章：地缘政治与供应链韧性

**【小白导读】**
这一章看Natera会不会因为某个国际政治事件（比如中美关税战、某国突然断供关键零件）而突然出大问题。

**【专业深挖】**

### 6.1 地理集中度风险
Natera的实验室、总部、研发几乎全部集中在美国本土（Austin, TX + San Carlos, CA），收入也几乎全部来自美国本土市场（详见第二章2.6）。这意味着公司对单一国家的政策风险（尤其是Medicare/CMS政策）高度集中，但对地缘政治冲突（如台海、俄乌等区域冲突）的直接敞口很低。

### 6.2 出口管制与关税
Natera的核心业务是"检测服务"而非硬件制造/出口，本身不直接受进出口关税影响。但公司依赖Illumina等供应商提供测序仪器和试剂耗材，这些供应链环节可能涉及部分进口元器件或化学试剂，具体关税敞口**[数据待查/不适用]**——公司未在最新10-Q/10-K中特别披露关税成本影响的量化数据。国际化收入（日本、欧盟市场准入刚起步，详见第二章）意味着未来关税/贸易政策变化对海外收入的潜在影响需要持续跟踪，但目前体量尚小。

### 6.3 供应链多元化进度
公司实验室集中在两个美国本土地点（San Carlos, CA + Austin, TX），未见披露海外产能布局计划，属地化风险主要是"美国本土集中"而非"海外供应链断供"风险。

### 6.4 关键原材料/环节依赖
对Illumina测序平台的依赖是公司最主要的单一供应商集中度风险（详见第二章波特五力"供应商议价权"评分6/10）。具体依赖比例、是否有替代测序平台供应商（如MGI、Thermo Fisher等）的备选方案**[数据待查/不适用]**。

### 6.5 货币与主权风险
公司收入绝大部分为美元计价，汇率敞口极低；国际化收入（日本、欧洲）占比尚小，货币风险总体可控。

### 6.6 极端情景假设
若中美贸易摩擦升级导致测序仪器/试剂进口成本大幅上升，可能对公司毛利率造成一定压力，但由于公司业务模式是"服务"而非"制造"，直接冲击程度预计低于设备制造类公司。地缘政治相关的尾部风险评分：**低-中**。

**【本节结论】**
Natera的地缘政治敞口总体较低——这是一家几乎完全在美国本土运营、收入几乎完全来自美国本土医保体系的公司，其最大的"政策风险"其实是国内医保覆盖政策（详见第十五、十八章），而非传统意义上的地缘政治/关税风险。这一点使其区别于半导体、消费电子等高度全球化的科技制造企业——对于寻求规避地缘政治尾部风险的投资者而言，Natera是一个相对"干净"的标的，但代价是其风险敞口高度集中在美国国内医保政策这一单一变量上。

### 8.1 ROIC vs WACC
由于Natera历年GAAP净利润持续为负（2021-2025年五年累计净亏损约18.5亿美元），传统意义上的ROIC（投入资本回报率）目前为**负值**，明显低于估算的WACC（约12.8%-13.0%，详见第十三章）。这是当前阶段公司"增长尚未转化为价值创造"的核心量化证据——但需要注意的是，公司的负ROIC主要是由于持续的高强度研发和商业化费用投入（而非资产减值或经营效率低下），随着收入规模效应持续显现（毛利率已从44.4%提升至64.7%），ROIC转正的时间窗口正在快速接近（分析师一致预期2027年GAAP净利润转正，来源：Simply Wall St整理的分析师一致预期，2026年9月）。

### 8.2 再投资率与边际回报
公司过去三年（2023-2025）研发+SG&A费用的复合增速与收入复合增速大体匹配甚至略低，2025年总运营费用$18.014亿（+44.6%）略高于收入增速35.9%，但这主要是因为公司在为2026年及以后的产能扩张、新适应症商业化做前置投入（如Prospera新LCD、Signatera国际化）。边际回报（每多投1美元费用带来的增量收入）正在改善但尚未达到"自我强化的正循环"阶段。

## 第十五章：ESG与监管/合规风险

**【小白导读】**
对于医疗诊断公司来说，"合规风险"往往比"环保风险"更致命——一次医保报销政策的变化，可能比任何环境问题都更直接影响公司的生死。

**【专业深挖】**

### 数据隐私与网络安全合规
Natera处理海量患者基因组数据，受HIPAA（美国健康保险流通与责任法案）等医疗数据隐私法规严格监管。截至本报告检索范围内，未发现近期重大数据泄露或HIPAA违规处罚的公开报道，但基因数据的敏感性意味着任何潜在的数据安全事件都可能对公司声誉和监管关系造成超出常规科技公司数据泄露事件的更大冲击，这是行业性的结构性合规风险，具体的公司专项合规评分**[数据待查/不适用]**。

### 反垄断调查现状
未检索到针对Natera的反垄断调查公开报道，**[数据待查/不适用，推断为不适用]**。

### 监管环境变化——LDT新规的兴废（详见第六、十二章）
这是本报告风险章节中最重要的监管事件：2024年5月FDA发布最终规则，试图将实验室自建检测(LDT)纳入医疗器械监管框架（意味着Natera的检测产品需要经过FDA上市前审批流程，将大幅提高合规成本和上市周期）；2025年3月31日联邦地区法院裁定撤销该规则，理由是LDT属于CLIA监管的"专业服务"而非FDA管辖的"医疗器械"；2025年9月19日FDA确认不上诉，正式恢复此前的监管现状（来源：Sidley Austin、ACLA、Congress.gov CRS Legal Sidebar，2025年）。**这一监管风险的解除，是过去18个月对整个行业最重大的正面监管事件**，直接移除了Natera商业模式面临的最大结构性监管尾部风险。但需要注意：监管的钟摆存在反复的可能性——未来国会或新一届FDA领导层仍可能通过立法或新规重新尝试将LDT纳入FDA监管，这一风险并未被"永久性"消除，只是当前阶段被推迟或搁置（详见第十八章风险矩阵）。

### 专利诉讼视为准合规风险（详见第十二章）
Natera与CareDx之间旷日持久的专利诉讼互诉（Natera曾胜诉获赔$9,630万后被推翻，CareDx对Natera的专利无效之诉被最高法院驳回其上诉请求），以及与Guardant Health的商业秘密诉讼（2025年8月已终止），构成了公司持续的法律/合规不确定性来源，具体财务影响详见第十八章风险量化。

### 劳工/供应链合规风险
未检索到与Natera相关的劳工争议或供应链合规负面报道，**[数据待查/不适用，推断为风险较低]**。

**【本节结论】**
Natera所在行业的ESG/监管风险核心并非传统意义上的"环保合规"或"劳工问题"，而是高度集中在"数据隐私+医保报销政策+FDA监管口径+专利诉讼"这四类行业特有的合规风险上。过去18个月这套风险组合的净效应是**结构性利好**（LDT新规撤销+医保覆盖持续扩容），但专利诉讼的反复性提醒投资者，这类风险不会"一次性出清"，而是会持续以个案形式出现,需要在第十八章中给予适当的概率×影响权重。

三者的分歧点主要在于："中端预期"隐含了当前37-38%的增速会在未来1-2年内向20%区间自然收敛（这是大多数卖方分析师的基准假设，因为高基数效应会逐渐显现），而"高端预期"则假设ASP提升($1,275→$2,000)和新适应症/新地理市场的贡献能够对冲基数效应,使增速维持在30%以上更长时间——**这一分歧的关键验证指标就是未来2-3个季度Signatera ASP的实际变化轨迹**（详见第二十章跟踪指标）。

**【本节结论】**
Natera增长故事中，**未来1-2年最先兑现、确定性最高的一块，是Signatera在已获Medicare覆盖的五大癌种内的检测量渗透率爬坡，以及Prospera受益于2026年8月新LCD的加速放量**——这两项都有管理层近期财报的直接数据支撑，属于"近在眼前、大概率兑现"的增长。而**规模想象空间最大但确定性最低的"期权型增长"，是日本/欧盟国际化商业化放量以及Signatera ASP能否真正提升至$2,000的成熟期目标**——前者受限于海外医保体系的复杂性和漫长的准入周期，后者虽有管理层明确数字目标但缺乏历史提价弹性数据支撑其可信度。这一结论将直接为第十七章"投资逻辑"提供弹药：买入Natera，本质上是在为"近期确定性增长"支付合理溢价，同时免费获得"国际化+ASP提升"这两项期权型增长的看涨期权。

**一句话结论**：Natera是一家**分子诊断/精准医疗**公司，目前主要靠**女性健康检测（Panorama/Horizon）的成熟现金流业务**打底，但市场真正看重的是**肿瘤MRD检测(Signatera)在医保覆盖持续扩容下的高速放量**；如果相信"检测量增长+ASP提升+医保覆盖扩容"这套过去两年被反复验证的三重驱动逻辑能够在竞争加剧的环境下再持续2-3年，当前估值在"偏贵但非明显泡沫化"区间，值得作为核心仓位持有；如果不相信Medicare报销政策能持续保持友好、或者认为Exact Sciences/Guardant Health的技术追赶将实质性侵蚀Natera的份额优势，则这家公司当前近20倍市销率的估值隐含风险很高，不适合作为价值型仓位配置的标的。

## 附录A：新手术语速查表

| 术语 | 大白话解释 |
|---|---|
| 液体活检（Liquid Biopsy） | 不用开刀取组织样本，只需抽一管血就能获取癌症/疾病相关基因信息的检测技术 |
| 循环肿瘤DNA（ctDNA） | 癌细胞死亡后释放到血液里的DNA碎片，携带癌症的基因印记，是液体活检的核心检测对象 |
| 微小残留病灶（MRD, Minimal Residual Disease） | 癌症患者手术或治疗后，体内可能残留的、常规影像学检查（如CT）看不见的极微量癌细胞，MRD检测就是用血液查这些"漏网之鱼" |
| 无创产前检测（NIPT） | 孕妇只需抽血，就能筛查胎儿是否有唐氏综合征等染色体异常，不需要传统羊水穿刺的有创操作 |
| 携带者筛查（Carrier Screening） | 备孕夫妻检测自己是否携带某些遗传病的致病基因，帮助评估后代患病风险 |
| 伴随诊断（Companion Diagnostic） | 与某种药物配套使用的检测，用来判断患者是否适合使用该药物，通常需要FDA专门批准 |
| Medicare本地覆盖决定（LCD, Local Coverage Determination） | 美国联邦医保(Medicare)针对某项具体检测/治疗，决定"在什么条件下医保愿意报销"的正式文件 |
| MolDX | CMS（美国医保）下属专门评估分子诊断类检测报销资格的项目机构 |
| 实验室自建检测（LDT, Laboratory Developed Test） | 由某个实验室自己研发、只在本实验室内部使用的检测项目，历史上由CLIA（而非FDA）监管 |
| 平均检测费率（ASP, Average Selling Price） | 每做一次检测平均能收到多少钱，是"检测量×ASP=收入"这个核心公式里的关键变量 |
| ROIC（投入资本回报率） | 公司每投入1块钱资本，能赚回多少钱，越高说明生意越好 |
| WACC（加权平均资本成本） | 公司从股东和债权人那里筹钱的综合成本，只有ROIC长期高于WACC，增长才是真正在创造价值而非摧毁价值 |
| DCF（现金流贴现估值法） | 把公司未来能赚到的所有现金，按一定折扣率换算成"今天值多少钱"的估值方法 |
| P/S（市销率） | 股价相对于每股收入的倍数，常用于给尚未盈利的成长股估值 |
| FCF Yield（自由现金流收益率） | 公司自由现金流相对于市值的比例，越高说明用同样的市值能买到越多真实的现金产出能力 |
| Beta（贝塔系数） | 衡量股票相对大盘的波动剧烈程度，大于1说明比大盘波动更剧烈 |
| 13F | 大型机构投资者（管理规模超过1亿美元）按季度必须向SEC披露持仓的文件 |
| Form 4 | 公司高管/董事买卖自家公司股票后必须在2个工作日内向SEC披露的文件 |
| 做空比例/回补天数(Days to Cover) | 做空比例指被卖空的股票占流通股的比例；回补天数指按平均成交量计算，空头需要多少天才能全部买回股票平仓 |
| NCCN指南及Category 1推荐 | 美国国家综合癌症网络(NCCN)发布的肿瘤治疗指南，Category 1是其中证据等级最高的推荐级别 |
| 伴随诊断/IVDR认证 | IVDR是欧盟《体外诊断医疗器械法规》，产品获得该认证是进入欧盟市场销售的准入门槛 |
