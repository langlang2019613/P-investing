## 受访人背景

王雁鹏，百度智能云 AI 计算首席科学家，长期负责百度 AI 基础设施与 Agent 技术体系的研发与落地。

本次访谈背景：AI 行业正从"模型能力竞赛"转向"Agent 商业化落地"，百度以"**芯云模体**"全栈战略切入 Agent 基础设施（Agent Infra）赛道。访谈聚焦：技术架构如何演进、巨头如何布局 Agent Infra、以及这场看似"隐秘"的战场为何决定 AI 时代真正的竞争格局。

---

## 一、最重要的时代判断：从模型到 Agent

> "行业正经历从模型时代到 Agent 时代的过渡。"

**模型时代的局限：**
- 竞争核心是参数量、Benchmark 分数、训练数据质量
- 价值交付路径：模型→API→用户，中间层薄，商业化难
- Token 成本是主要变量，定价模型高度同质化

**Agent 时代的新逻辑：**
- Agent 不只是调用大模型，而是**任务理解→规划→执行→反馈**的完整闭环
- 价值交付从"回答问题"升级为"完成任务、交付结果"
- 衡量指标从"Token 消耗量"转向**"日活智能体数"（DAA，Daily Active Agents）**
- 李彦宏的定义："有多少 Agents 在给人类干活，并交付结果"——才是 AI 创造价值的真正量化

**为什么这场战场"隐秘"？**
Agent Infra 不在用户界面层（C 端产品），而在技术栈的中间层——沙箱执行环境、工具调度、多 Agent 协调、长上下文管理。大众感知不到，但这是 Agent 能否稳定工作的核心基础。

## 二、百度 Agent Infra 战略：芯云模体

### 四层全栈体系

```
体（Agent 应用层）   ←  百度搭子 / 秒哒 / 伐谋 / 一镜
模（基础模型层）     ←  文心 5.1
云（AI 云平台层）    ←  千帆平台（Qianfan）
芯（芯片计算层）     ←  昆仑芯 P800
```

每一层都是自研，形成闭环，降低对外部供应商的依赖，同时实现跨层协同优化。

### 千帆平台：Agent 执行环境

从早期的"模型即服务（MaaS）"平台，演进为完整的 **Agent 执行环境**：

| 能力 | 描述 |
|------|------|
| 沙箱执行 | 隔离的任务运行环境，支持代码执行、浏览器操作、文件处理 |
| 工具调度 | 动态选择和调用工具（搜索、计算、数据库等） |
| 多 Agent 协调 | 支持多个 Agent 协作完成复杂任务 |
| 长上下文管理 | KVCache 缓存，大幅降低多轮对话的 Token 成本 |

**已披露的性能数据：**
- Token 消耗量节省 **23%**
- 任务成功率超 **95%**

### 昆仑芯 P800：国产 AI 芯片的竞争力

- 在国产 AI 芯片中推理 Token 吞吐量处于领先位置
- 已实现**超万卡交付**规模
- 最新配置：256/512 卡超节点
- 推理效率据称提升 50%（对比上一代）
- 招商银行已有超 **50% 的 AI 智能体**运行于国产算力之上

### 系统工程降本：削峰填谷

通过三项技术实现算力利用率最大化：
1. **潮汐调度** — 根据需求波动动态分配算力资源
2. **P/D 分离** — Prefill（预填充）与 Decode（解码）分离部署，提高 GPU 利用率
3. **KVCache** — 长对话场景下的键值缓存复用，避免重复计算

## 四、AI Infra 公司的战略转型

**百度的财报重构（2025Q3 起）：**

原来的分类：广告收入 / 非广告收入  
新的分类：**AI 新业务 + 传统业务**

原因：广告与 AI 的经营逻辑完全不同，投资者需要清晰看到 AI 战略的独立价值。

**核心业务数据：**

| 指标 | 数值 |
|------|------|
| 2025 年 AI 新业务营收 | 400 亿元 |
| 同比增速 | +48% |
| 占核心业务营收比例 | 约 39% |

这意味着百度传统的搜索广告业务虽然仍是营收主体，但 AI Infra 和 Agent 业务已成为增长引擎，且占比持续提升。

**沈抖（百度智能云总裁）的核心判断：**
> "模型会越来越普及，但真正拉开差距的，是企业能不能把 AI 深度接入自己的业务流程。"

这句话点出了 Agent Infra 的真正战场：不是模型本身，而是**企业落地的深度和广度**。

## 五、Agent Infra 的竞争格局

**为什么巨头都在布局？**

| 参与者 | 布局方向 |
|--------|---------|
| 百度 | 芯云模体全栈，千帆平台作为 Agent 执行层 |
| 阿里 | 通义+百炼平台+阿里云 Agent 基础设施 |
| 腾讯 | 混元模型+企业微信 Agent 生态 |
| 字节跳动 | 豆包+火山引擎 |
| 硅谷：AWS/GCP/Azure | Bedrock/Vertex AI/Azure AI Foundry |

**竞争核心变量：**
1. **任务成功率** — 不是模型评分，而是真实业务任务的完成率
2. **系统可靠性** — 沙箱稳定性、工具调度容错率、多 Agent 协调一致性
3. **成本效率** — 单位任务完成的 Token 成本
4. **生态深度** — 能接入的企业系统和工具的广度

**DAA 指标的意义：** 李彦宏推出"日活智能体数"而非"日活用户数"或"Token 消耗量"，是在重新定义 AI 公司的核心 KPI——从"有多少人用"转向"AI 在替人完成多少工作"。

## 六、行业趋势判断

### 短期（1–2 年）
- Agent Infra 基础设施竞争加剧，API 定价持续下行
- 千帆类平台从"接入模型"走向"编排 Agent 工作流"
- 企业采用率快速提升，但大多数仍处于"试用"而非"深度嵌入"阶段

### 中期（2–4 年）
- 能证明 ROI 的垂直行业 Agent 方案形成差异化竞争壁垒
- Agent Infra 逐渐向操作系统层沉淀，高度粘性
- 国产芯片能力提升将显著降低国内 AI 推理成本，提高 Agent 商业可行性

### 长期（4年+）
- Agent 将渗透入 CRM、ERP、供应链等核心企业系统
- "AI 员工"与"人类员工"的协作边界将重新定义企业组织架构
- 算力、模型、Agent 平台的竞争将趋于寡头格局

---

## 七、核心结论

| 维度 | 结论 |
|------|------|
| 时代判断 | 从模型时代到 Agent 时代是不可逆的转变 |
| 百度定位 | 已从搜索公司转型为 AI Infra 公司，全栈布局 |
| 竞争护城河 | 芯云模体闭环 + 千帆平台 Agent 执行能力 + 大规模落地数据 |
| 核心新指标 | DAA（日活智能体数）比 Token 消耗量更真实反映 AI 价值 |
| 最大变量 | 企业能否把 AI 深度嵌入核心业务流程，而非停留在边缘工具层 |
| 关注数据 | AI 新业务营收增速（2025: +48%）/ DAA 增长 / 千帆平台活跃度 |

**这场"隐秘战场"的本质：** 谁建好了 Agent 运行的基础设施，谁就卡住了 AI 从工具变成员工的关键入口。
