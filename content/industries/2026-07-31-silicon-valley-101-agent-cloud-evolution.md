# 算力革命与Agent云的三重进化——云厂商架构升级与"度量衡革命"

**来源：硅谷101 | 发布时间：2026年7月22日 | 时长：26分14秒**

## 核心论点

这期硅谷101触及了当前AI产业投资中最确定的主线之一：**云产业正在经历结构性的架构升级**，而这场升级的深度和广度远超市场预期。云厂商不再是单纯的算力租赁商，而是正在成为AI工作流的全栈基础设施提供方。这对于MSFT、AMZN、GOOG等主要云服务商的估值重构有直接含义。

---

## 一、云计算的三阶段演进模型

郑然（百度智能云）在视频中系统梳理了云计算从诞生至今的演进路径，并将其划分为三个关键阶段：

### 第一阶段：互联网云（2006-2018）
这一阶段的云计算以**服务互联网软件和网站**为核心使命。AWS的崛起让企业从自建IDC的重资产模式切换到按需租用的轻资产模式。技术核心是虚拟化、存储和网络带宽。这一阶段的代表性服务是EC2、S3、RDS等标准化基础设施层。

云厂商的护城河在于规模经济——服务器越多、数据中心越大，边际成本越低，定价权越强。这阶段阿里云、腾讯云、百度智能云也陆续跑通了国内版本的IaaS商业模式。

### 第二阶段：GPU云（2018-2025）
大模型的崛起彻底改变了云计算的需求结构。训练GPT-3、GPT-4这类模型需要数万块GPU并行运算，传统CPU服务器完全无法胜任。云厂商开始大规模采购英伟达GPU，并以"GPU时"为计价单位向模型公司、研究机构出售算力。

这一阶段的关键变化：
- **计价单位**从CPU小时变成GPU小时，再到H100/A100/H200等具体型号
- **带宽需求**急剧膨胀，InfiniBand高速互联成为标配
- **能耗成本**成为数据中心选址的决定性因素（水电资源、气候条件）
- **供给瓶颈**完全转移到英伟达，云厂商话语权下降

这一阶段云厂商的地位略显尴尬——一方面要向英伟达采购贵价GPU，另一方面又面临模型公司自建算力中心的竞争（OpenAI、Meta等）。但巨大的训练和推理需求仍然支撑了云厂商的高增长：Azure AI +43%、AWS +21%、Google Cloud +28%（2026年Q2数据）。

### 第三阶段：Agent云（2025至今）
这是视频的核心主题，也是当前云计算最重要的结构性转变。

**Agent不是更聪明的聊天机器人**，而是能够自主执行多步骤任务的AI系统——查邮件、写代码、调API、做决策，持续运行数小时甚至数天而不需要人类干预。当AI从"答题模式"切换到"执行模式"，对基础设施的要求发生了质的变化。

## 二、Agent云：为什么架构必须重构？

### 问题1：为什么模型足够聪明，但Agent仍会"掉链子"？

郑然在视频中给出了非常清晰的解释。Agent的失误率不是模型智能不够的问题，而是**系统工程问题**。

一个典型的Agent任务可能包含：
1. 理解用户意图（调用LLM）
2. 拆解子任务（规划层）
3. 调用外部工具（搜索、数据库、API）
4. 处理工具返回结果（上下文管理）
5. 记忆历史状态（跨会话持久化）
6. 生成最终输出（再次调用LLM）

每一个步骤都有失败概率。如果一个10步任务每步成功率99%，最终成功率只有约90%。如果每步95%，整体只有60%。这就是"复杂度诅咒"。

要提高Agent可靠性，必须：
- 更稳定的**工具调用层**（Tool Calling，标准化接口）
- 可持久化的**记忆系统**（长期上下文、向量数据库）
- 完善的**错误恢复机制**（Retry、Fallback、Checkpoint）
- 严格的**安全与权限管控**（防止Agent越权操作）

这些能力**超出了单纯GPU算力的范畴**，需要云厂商提供全栈托管解决方案。

### 问题2：云厂商为什么不能只卖算力？

GPU云阶段，云厂商本质上是"GPU批发商"——用户拿到裸机，自己搭建训练环境。但Agent云阶段，这个模式行不通：

- Agent需要**持久化状态**，而GPU实例本质上是无状态计算资源
- Agent需要**低延迟工具调用**，而跨系统API集成需要云层面的统一管理
- Agent需要**多模态输入处理**，涉及图片、音频、视频的实时处理能力
- Agent需要**细粒度安全策略**，不同Agent有不同的数据访问权限

云厂商提供的不再是"算力"，而是**AI工作流的操作系统**。这大幅提高了客户黏性（迁移成本），也让云厂商有更高的定价权和更丰厚的毛利率。

微软Copilot、亚马逊Bedrock Agents、谷歌Vertex AI Agent Builder都是这个方向上的产品化尝试。

## 三、"度量衡革命"：从Token到任务结果

这是视频中最有投资含义的概念。

**现有计价方式**：云厂商按Token消耗计费（输入Token + 输出Token）。用户为算力买单，而非为结果买单。

**问题**：用户不关心用了多少Token，用户只关心任务有没有完成。一个复杂任务消耗100万Token，但如果最终失败，用户仍然付了费用但没有价值产出。

**度量衡革命**：转向**结果导向计费**——按成功完成的任务数量、按产生的业务价值来计费。

这个转变对云厂商意味着：
1. **商业模式升级**：从纯资源出租变成SaaS式订阅（更高ARR可见度）
2. **激励对齐**：云厂商有动力持续优化Agent成功率（而不是让用户消耗更多Token）
3. **护城河加深**：成功率数据成为核心竞争力，而不是GPU数量

类比：AWS从按EC2小时收费 → Lambda按函数调用次数收费 → 未来按"Agent任务成功完成次数"收费。每次迁移都提高了云厂商在价值链中的位置。

## 四、机器人与AI融合：鞠笑竹的人形机器人视角

北京人形机器人创新中心的鞠笑竹提供了一个更前沿的视角：**人形机器人是Agent云在物理世界的延伸**。

人形机器人的控制系统与AI Agent本质相同：
- 感知层（视觉、触觉传感器）= 多模态输入
- 规划层（任务分解、路径规划）= LLM + 规划算法
- 执行层（电机控制）= 工具调用
- 记忆层（历史动作、环境地图）= 持久化存储

这意味着支撑AI Agent的云基础设施，同样是支撑下一代机器人产业的基础设施。而云厂商掌握的边缘推理、低延迟计算、实时数据流处理能力，将是机器人产业化的关键卡脖子资源。

## 五、投资含义

### 对云厂商的影响

| 云厂商 | Agent云核心产品 | 竞争优势 | 当前状态 |
|--------|---------------|---------|---------|
| **Microsoft Azure** | Copilot Studio, Foundry | 企业客户基础（Office生态）、OpenAI独家 | Azure +43%，Copilot席位3000万 |
| **Amazon AWS** | Bedrock Agents, Nova | 最大IaaS市场份额、企业关系 | AWS稳健增长，Agent产品加速 |
| **Google Cloud** | Vertex AI, Gemini API | TPU自研优势、搜索数据护城河 | 云+82%，但成本高企 |
| **百度智能云** | 文心大模型、千帆 | 国内市场、中文能力、自动驾驶数据 | 未上市/A股，受益国内AI建设 |

### 关键判断

**做多逻辑**：Agent云阶段，云厂商ARPU（每用户平均收入）有望大幅提升，因为他们售卖的不再是裸GPU时间，而是包含模型、工具链、记忆、安全的完整解决方案，溢价空间显著。

**风险点**：大模型能力继续提升后，推理成本持续下降，Token价格可能进入价格战。但度量衡从Token向任务结果的切换，将帮助云厂商脱离这场价格战，维持定价权。

**SMH/半导体视角**：Agent云对GPU的需求仍然旺盛，但需求结构从训练（大规模集中采购）转向推理（分散、持续、更低延迟）。这对NVDA的推理芯片（Blackwell NVL4、NVL8推理配置）是利好，对AMD和英特尔的推理机会也有正面影响。
